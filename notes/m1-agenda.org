** 2. The surface M1 builds on -- quoted from the current sources
The two structs in =data/rope/core.rkt= and every tree algorithm stay untouched, so M1
adds a compile-time index over the dictionary that already exists.

#+begin_src racket
;;   empty       -- the empty chunk value
;;   length      -- chunk → nat        (element count)
;;   ref         -- chunk nat → element
;;   slice       -- chunk nat nat → chunk   (Racket convention: [start, end))
;;   append      -- chunk chunk → chunk
;;   width       -- chunk → nat        (index span; procedure or per-element constant)
;;   limit       -- max elements per leaf
;;   merge-limit -- concat merges boundary leaves when combined length ≤ this
(struct chunk-dict (empty length ref slice append width limit merge-limit) #:authentic #:sealed)

;; Build a `chunk-dict`: `#:width` takes a procedure or a per-element constant, and
;; `#:merge-limit` defaults to `#:limit`.
(define (make-chunk-dict #:empty e #:length len #:ref ref #:slice slice #:append app
                         #:width [width 1] #:limit limit #:merge-limit [merge-limit limit])
  (chunk-dict e len ref slice app
              (if (procedure? width) width (λ (c) (* width (len c))))
              limit merge-limit))
#+end_src

The dictionary carries eight fields, and the type record M1 writes carries nine keys --
the eight above plus =chunk?=, which ADR-001 places at the typing layer (=notes/m1.org= §4).

Core operations take the dictionary first, so every op M1 generates expands to a call
whose first argument is the type's dictionary constant:

#+begin_src racket
(define (rope-ref σ ρ i)
  (let loop ([ρ ρ] [i i])
    (if (leaf? ρ)
        ((chunk-dict-ref σ) (leaf-chunk ρ) i)
        (let ([n (rope-length (node-left ρ))])
          (if (< i n)
              (loop (node-left ρ) i)
              (loop (node-right ρ) (- i n)))))))
#+end_src

The runtime constants M1 supersedes, and the converters it moves:

#+begin_src racket
(define string-dict (make-chunk-dict #:empty "" #:length string-length #:ref string-ref
                                     #:slice substring #:append string-append
                                     #:width 1 #:limit 512 #:merge-limit 64))

;; Byte chunks copy cheaper than string chunks, so bytes-dict takes a larger `limit`. Its
;; merge-limit moved from `limit`/4 to `limit`/8 on the rerun that measured the smaller edit
;; tail at both matched sizes. See notes/m0.org §3.2 rows 8 and 12.
(define bytes-dict (make-chunk-dict #:empty #"" #:length bytes-length #:ref bytes-ref
                                    #:slice subbytes #:append bytes-append
                                    #:width 1 #:limit 2048 #:merge-limit 256))

;; Token ropes take `limit` 128 with `merge-limit` 16 -- the measured balance of typing
;; and reading for vector chunks of tokens. See notes/m0.org §3.2 row 21.
(define vector-dict (make-chunk-dict #:empty (vector) #:length vector-length #:ref vector-ref
                                     #:slice vector-copy #:append vector-append
                                     #:width 1 #:limit 128 #:merge-limit 16))

;; (string->rope str) is string-dict's constructor: (chunk->rope string-dict str).
(define (string->rope str) (chunk->rope string-dict str))

;; (bytes->rope bstr) is bytes-dict's constructor: (chunk->rope bytes-dict bstr).
(define (bytes->rope bstr) (chunk->rope bytes-dict bstr))

;; Return the characters of `ρ` as one string.
(define (rope->string ρ)
  (define out (make-string (rope-length ρ)))
  (rope-fold-chunks (λ (i c) (string-copy! out i c) (+ i (string-length c))) 0 ρ)
  out)

;; Return the bytes of `ρ` as one byte string.
(define (rope->bytes ρ)
  (define out (make-bytes (rope-length ρ)))
  (rope-fold-chunks (λ (i c) (bytes-copy! out i c) (+ i (bytes-length c))) 0 ρ)
  out)
#+end_src

- Create it with =#lang racket/base=, one =begin-for-syntax= block, and one export
  clause, =(provide (for-syntax (all-defined-out)))=. A module with no =provide= exports
  nothing, so a macro module cannot pull the record from it (=racket-facts.md= §4).
- Transcribe the record, the key order, and the resolver from =notes/m1.org= §4 as
  written there. Both =data/rope/ops.rkt= and step 4's accessor require this module, so
  =rope-type= is defined once: two module instances each defining their own struct make
  the cross-module check fail, which is the trap =racket-facts.md= §11 records against
  the legacy struct types.
- Add =arg->pattern= here, not inside a macro module.
- Add =arg->use= and =check-rope= the same way.
- Add =rope-type-primitive= and =dict-accessor=, which step 4's accessor needs.
- The helpers sit here so both macro modules share one definition.
- Keep the messages in domain terms: =resolve-rope-type= reports what the user wrote and
  never a struct name or a dictionary (=notes/overview.org= §4.1).

#+begin_src racket
;; data/rope/private/type-stx.rkt
#lang racket/base
(require (for-syntax racket/base))
(provide (for-syntax (all-defined-out)))

(begin-for-syntax
  ;; A rope type: a nominal name, the dictionary it is realized by, and the primitive syntax
  ;; of every chunk-algebra operation (kept so M3 can inline them).
  (struct rope-type (name dict-id primitives) #:transparent)

  ;; Fixed key order: the eight dictionary fields plus chunk?, which the dictionary itself
  ;; does not carry -- ADR-001 places chunk? at the typing layer.
  (define type-keys '(empty length ref slice append width limit merge-limit chunk?))

  ;; Resolution reads the lexical context of the expansion. Standard mechanism: struct
  ;; identifiers, via syntax-local-value. No local-expand, no syntax properties (ADR-003).
  (define (resolve-rope-type stx)
    (define v (syntax-local-value stx (λ () #f)))
    (cond [(rope-type? v) v]
          [else (raise-syntax-error #f "not a rope type" stx)])))
#+end_src

** 4. Step 2 -- =define-rope-type= (=data/rope/type.rkt=) (Not started)
| Field   | Value                                                     |
|---------+-----------------------------------------------------------|
| Writes  | =data/rope/type.rkt=                                        |
| Depends | step 1                                                    |
| Exit    | one type expands; the limit bound is refused at expansion |
| Cites   | =notes/m1.org= §5; ADR-019                                  |

- Transcribe §5's rule as written, including the =#:fail-when= clause: merge-limit must
  stay between 1 and =limit=, which is the structural invariant that =rope-valid?= checks
  in =core.rkt=, so the bound is tested at expansion time and never at runtime.
- Keep the *original* =#:width= syntax on the record. =make-chunk-dict= wraps a constant
  today; M3 inlines =(* 1 (string-length c))= instead of calling the wrapper, so the
  record stores the primitive the body started with (ADR-017, ADR-005).
- Do not add =#:instances=. Instances are M4, and equality, hashing, and ordering are
  class operations, so the record holds no entry for them (ADR-010).
- Export both roles through =(provide (all-defined-out))=: =τ:dict= is the runtime
  constant and =τ= is the syntax binding, so a type is renamed and imported like any
  name. Nominal identity is binding identity, and the legacy =rope:string= convention
  is gone -- =string-rope= coexists with =string=.

The rule M1 writes into =data/rope/type.rkt=, quoted from =notes/m1.org= §5:

#+begin_src racket
;; data/rope/type.rkt
#lang racket/base
(require (for-syntax racket/base syntax/parse data/rope/private/type-stx)
         data/rope/core
         syntax/parse/define)

(provide define-rope-type)

(begin-for-syntax
  (define-syntax-class prim #:description "a primitive operation" (pattern id:id))
  (define-syntax-class nat #:description "a natural number"
    (pattern n:integer #:fail-unless (>= (syntax-e #'n) 0) "negative limit"))
  (define-syntax-class prim-or-lit #:description "a primitive or a literal"
    (pattern (~or id:id lit:literal))))

(define-syntax-parse-rule (define-rope-type τ:id
  #:chunk?       chunk?:prim
  #:empty        empty:prim-or-lit
  #:length       len:prim
  #:ref          ref:prim
  #:slice        slice:prim
  #:append       app:prim
  #:width        [width (~or nat:integer prim)]   ; constant, or a chunk procedure
  #:limit        limit:nat
  #:merge-limit  [merge-limit nat])

  #:fail-when (or (< (syntax-e #'merge-limit) 1)
                  (> (syntax-e #'merge-limit) (syntax-e #'limit)))
          "merge-limit must be between 1 and limit (ADR-019)"

  (begin
    (define τ:dict (make-chunk-dict #:empty empty #:length len #:ref ref
                         #:slice slice #:append app #:width width
                         #:limit limit #:merge-limit merge-limit))
    (define-syntax τ (rope-type 'τ #'τ:dict
                         (list empty len ref slice app width limit merge-limit chunk?)))))
#+end_src

- Check: a smoke case in =tests/type-tests.rkt= defines one type, reads all nine record
  keys, and confirms =(chunk-dict-limit τ:dict)= equals the declared =#:limit=.
- Check: the record's primitive list ends with =chunk?=, matching =type-keys= order (§3),
  so the eight dictionary slots keep indices 0 through 7 and never need shifting.
- Check: expansion rejects =#:merge-limit= above =#:limit= and below 1. A compile-time
  error cannot be caught at runtime, so the assertion belongs to step 8's harness, not
  to a runtime =check-exn=.

The row macro, quoted from =notes/m1.org= §7:

#+begin_src racket
(begin-for-syntax
  ;; τ marks a rope argument; concrete names (fixnum, elem, α) are unchecked in M1.
  (define (rope-arg? spec) (eq? (syntax-e spec) 'τ)))

(define-syntax-parse-rule (define-rope-op name:id core:id (arg ...) result:list #:dict)
  #:with (pat ...) (map arg->pattern (syntax->list #'(arg ...)))
  #:with (a ...)   (map arg->use    (syntax->list #'(arg ...)))
  (define-syntax-parse-rule (name τ:id pat ...)
    #:do [(define tp (resolve-rope-type #'τ))
          (for ([arg (in-list (syntax->list #'(arg ...)))])
            (when (rope-arg? arg) (check-rope 'name tp)))]
    #:with dict (rope-type-dict-id tp)
    (core dict a ...)))
#+end_src

- =check-rope= asserts each argument is itself a type id and that every =τ= argument
  agrees. The message names the ropes and their types, never a dictionary or a struct:

#+begin_src text
rope-concat: ropes of different types
  a : string-rope
  b : bytes-rope
#+end_src

- Arity errors come free from the pattern arity of =syntax/parse=, so no row checks one.
- The leading type argument is parsed by *one shared syntax class*, so M2 widens the
  grammar without touching a row and the explicit form stays valid forever (T0, §2.2).
- ⟦verify⟧ that one syntax class accepts a type id now and an inferred position later.

The accessor, quoted from =notes/m1.org= §8:

#+begin_src racket
(begin-for-syntax
  ;; τ.op resolves τ statically: a type id gives the primitive as syntax; a variable holding a
  ;; dictionary gives the runtime accessor. One text, two expansions (ADR-005).
  (define-syntax-parse-rule (τ.op τ:id key:id . rest)
    #:do [(define v (syntax-local-value #'τ (λ () #f)))]
    #:with prim (cond [(rope-type? v) (rope-type-primitive v (syntax-e #'key))]
                      [else (datum->syntax #'τ (list (dict-accessor (syntax-e #'key)) #'τ))])
    (prim . rest)))
#+end_src

- The accessible key set is exactly =type-keys= from step 1, which is why no substitution
  machinery is needed: this replaces the legacy =star-substitute= and =τ.key= binding
  machinery (=notes/overview.org= §4.1).
- ⟦verify⟧ two risks that =notes/overview.org= §4 names: =syntax-local-value= must see
  the *caller's* lexical context, so pass the op's syntax down rather than rewalking,
  and it must work inside nested macros and =for= bodies. Both are checked first by
  probe cases in =tests/type--ops-tests.rkt=, before step 9 measures anything.

** 14. Traps this pass has hit before, in the same toolchain
- A module with no =provide= exports nothing, and a relative path resolves against the
  requiring file (=racket-facts.md= §4).
- A stale =.zo= silently runs old code, and macro modules are not exempt from the trap
  (=racket-facts.md= §5). Compile first, then run.
- Defining =round=, =max=, or any name containing a =/= shadows the builtin and gives
  =application: not a procedure=, which reports the callee's value, not the argument
  (=racket-facts.md= §3, §8). =bytes/elem= is a division operator until shadowed.
- =command-line= reads its =#:args= as strings, not bytes (=racket-facts.md= §3), the
  form =benchmarks/latency-gate.rkt= passes to the sweep.
- =current-memory-use= undercounts struct and pair allocation, and =VmRSS= deltas over
  a live rope often read zero (=racket-facts.md= §2), since the CS backend reuses pages.
- Measure retained bytes with the tree-overhead formula rather than procfs (=racket-facts.md=
  §2), and read =/proc/self/status= with =file->bytes=, since =file->lines= truncates it.
- Paren-heavy edits break a *later* form when one close is missing (=racket-facts.md=
  §8). Check the paren balance after each edit to a macro module.
