* Development directories stay out of the build

Setup builds the library only: =tests/=, =benchmarks/=, =tools/=, =notes/=, and =reports/=
each carry an =info.rkt= declaring =compile-omit-paths 'all=, so setup never compiles
a file inside them, and =raco setup --pkgs data-rope= cannot fail on the broken fixtures.

An omitted directory is still a directory of files: =tools/delimiter_doctor.py= reads
the fixtures from the working tree, and =raco make= still compiles any file it names,
so omission costs nothing a run needs. A test or a benchmark compiles itself first:
=raco make tests/X.rkt= and =raco make benchmarks/latency-gate.rkt= both work.

The entry sits in each directory rather than the package root file: setup reads a
directory's own =info.rkt= when it scans that directory, while entries declared at the
root did not reach its children under Racket v9.3 [cs], so a per-directory entry holds.

Cover walks directories rather than honoring an omission, so its command names the
paths it covers: =raco cover -b data/rope.rkt data/rope tests=. Package mode walks
=tools/= and reads the broken fixtures, which ends the run before a report is written.
